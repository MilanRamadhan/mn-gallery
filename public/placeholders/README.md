# Placeholder images

These WebP files are intentionally abstract and local. No photographs of unrelated couples
were downloaded. Replace them through the admin uploader after Supabase is connected, or edit
the demo paths in data/demo.ts.

Regenerate the complete set with:

```bash
npm run assets:placeholders
```

Recommended final formats are AVIF or WebP. Keep the original aspect ratio, provide meaningful
alt text, and aim for a maximum long edge around 2400 pixels before upload.
